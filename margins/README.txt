Margins door page

What it is: a tiny page that carries Zoi's own Home Screen icon and opens the
Margins library on claude.ai. It holds no data.

Where it goes: put this whole "margins" folder at the top of the GitHub Pages
site that hosts Lines, so it is served at  <site>/margins/

Files
- index.html                 the door page
- apple-touch-icon.png       Home Screen icon (180 x 180), drawn by Pen Pal
- icon-512.png               larger copy of the same icon
- alt-apple-touch-icon-bagel.png / alt-icon-512-bagel.png
                             second option (the bagel Wren drew).
                             To use it, rename it over the two files above.

To swap in Zoi's own drawing: export a square PNG, 180 x 180, no transparency,
and save it as apple-touch-icon.png (and a 512 x 512 copy as icon-512.png).

How Zoi adds it
1. Open <site>/margins/ in Safari.
2. Share, then Add to Home Screen. Turn OFF "Open as Web App" the first time.
3. Tap the new icon: it should go straight to Margins.
