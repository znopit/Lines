# Lines

Leon × Zoi 的私人图书馆。这个仓库只存放网站本身（设计与功能），不存放任何故事内容。
内容由你在设备上导入，只保存在那台设备的浏览器里，任何时候都不会上传。

## 使用

1. 在【文件】里长按 Lines 文件夹 → 压缩，得到一个 .zip。
2. 打开图书馆 → MENU → Library → Import。
3. Safari 分享 → 添加到主屏幕，之后可以离线打开。

iPhone、iPad、电脑各自保存一份。更新内容时，重新导入新的 zip 即可，同名文件会被替换。

## 文件格式

主线文件不用改：正文里单独一行的「第93篇」会被自动拆成单篇，文件名里的「93-114｜洛杉矶｜上海篇」给出篇章名。

其他文件在开头加几行：

```
类型：1v1
人物：Zoi × Evan
篇号：163
标题：仙本那早餐
---
正文……
```

- 类型：1v1、支线、短信、日记、物品、存档、留言、档案、插画、概览／研究
- 短信的人物写 Leon × Zoi、Zoi × Evan、Zoi × Hudson，群聊写「群聊」
- 置顶、备注名、群名和群昵称存在 lines-settings.json 里，导出时一起带走
- 可选：日期、图片（填图片文件名）、篇章（主线单篇文件用）
- 没有开头这几行的文件，按文件名里的关键词归类（1v1、支线、短信、日记、档案、存档、物品、留言、概览、术语、解析）

## 图片

- 在 Gallery 里可以直接添加图片、改归属、删除；照片默认按人物颜色显示成单色印刷效果，可以关掉

- 放在名为「插画」或「速写」的文件夹里 → Zoi 的速写本
- 文件夹或文件名里带人物名字 → 归到该人物
- 放在「封面」文件夹里，文件名为 main、dialogues、side、messages、studies、gallery 或 Leon、Zoi、Evan、Hudson → 成为对应板块或人物页的封面
